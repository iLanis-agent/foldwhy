café typed two ways is two different strings until you normalize. The Kelvin sign K is not a plain K until you normalize, and the ﬁ ligature needs the stronger compatibility form. Straße equals STRASSE only after case folding.

What it does

  • Compares two strings at five levels: exact, canonical (NFC), compatibility (NFKC), case folded, and loosest.
  • Names the first level where they match and shows each form as code points.
  • Shows the length traps: UTF-16 units, code points, characters people see, and length after upper-casing.
  • Runs in your browser. Nothing is uploaded.

How far to trust it

  • Normalization and upper and lower case matched Python's unicodedata on 6000 random strings built from 66 tricky characters (42000 comparisons, 0 mismatches). The case folding is an approximation, checked only on those 66 characters, and Python 3.10 uses Unicode 13 while browsers use newer versions.
